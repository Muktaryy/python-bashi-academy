# PY-005 — Employee Eligibility Checker

## Objective

Create a Python program that determines whether an employee is eligible for a company benefit based on their age.

## Business Rule

An employee is eligible if they are **18 or older**.

## Requirements

- Store the employee's age in a variable.
- Use a comparison operator to check the age.
- Use `if` and `else`.
- Display the appropriate eligibility message.

## Python Concepts Used

- Variables
- Integers (`int`)
- `if`
- `else`
- Comparison operators
- `>=`
- Boolean results
- Indentation
- `print()`

## Comparison

The program uses:

```python
age >= 18

This means:
The employee's age must be greater than or equal to 18.
Examples
For:
age = 25
Output:
Employee is eligible.
For:

Output:

For:
