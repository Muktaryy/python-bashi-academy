# PY-003 — Employee Status Checker

## Objective

Create a Python program that checks whether an employee is active or inactive.

## Requirements

- Store the employee's status in a Boolean variable.
- Use an `if` statement to check the status.
- Use `else` for the inactive case.
- Display the appropriate employee status.

## Python Concepts Used

- Variables
- Boolean (`bool`)
- `if`
- `else`
- Conditions
- Indentation
- `print()`

## Example

When:

```python
is_active = True

The program displays:
Employee Status: Active
When:
is_active = False
The program displays:
Employee Status: Inactive
