# PY-002 — Employee Salary Calculator

## Objective

Create a Python program that calculates an employee's annual salary based on their monthly salary.

## Requirements

- Store the monthly salary in a variable.
- Calculate the annual salary.
- Display the monthly salary.
- Display the annual salary.

## Python Concepts Used

- Variables
- `int`
- Arithmetic operators
- Multiplication (`*`)
- `print()`
- f-strings

```text
Annual Salary = Monthly Salary × 12
